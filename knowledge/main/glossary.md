# Cordys CRM · 核心术语表

> 本文件定义 Cordys CRM 业务域内的通用术语。当 AI 对任何术语含义不确定时，必须查本表。若术语在表中不存在，向用户澄清。

---

## 一、业务模块术语

| 术语 | 英文标识 | 定义 | 关联模块 |
|---|---|---|---|
| **线索** | Clue | 潜在客户的原始信息，尚未通过验证。是 CRM 业务漏斗的最上游入口。可转入客户，也可回收到线索池。 | clue |
| **线索池** | CluePool | 线索的公共容器。未分配或被回收的线索进入线索池，管理员可批量分配，销售可主动领取。 | clue |
| **线索容量** | ClueCapacity | 单个销售人员持有的线索数量上限。超过容量时不能再领取/分配新线索，需先处理存量。 | clue |
| **客户** | Customer | 通过验证的企业/组织，是 CRM 业务的核心主体。关联联系人、商机、合同、订单等。 | customer |
| **联系人** | CustomerContact | 客户企业中的具体人员。一个客户可有多个联系人，分主次。 | customer |
| **公海** | CustomerPool | 客户的公共容器（对应线索池）。无人负责的客户进入公海，可被领取或分配。 | customer |
| **客户协作** | CustomerCollaboration | 除了主负责人之外，其他销售人员参与某客户跟进的协作关系。 | customer |
| **客户容量** | CustomerCapacity | 单个销售人员持有的客户数量上限。机制同事线索容量。 | customer |
| **商机** | Opportunity | 与客户之间的一个具体销售机会。通常经历：初步沟通→需求确认→方案报价→商务谈判→赢单/输单。 | opportunity |
| **商机阶段** | OpportunityStage | 商机在销售漏斗中的位置。默认含：初步接触、需求确认、方案制定、商务谈判、合同签订。阶段可配置。 | opportunity |
| **报价** | OpportunityQuotation | 针对某商机向客户提供的正式报价单。含产品、数量、单价、折扣等。 | opportunity |
| **赢单** | Opportunity Success | 商机状态为"赢"，即客户确认采购。赢单后通常进入合同签订环节。 | opportunity |
| **输单** | Opportunity Fail | 商机状态为"输"，即确认丢单。需记录输单原因。 | opportunity |
| **合同** | Contract | 与客户签署的正式法律文件。关联订单、收款计划、发票。是收入确认的依据。 | contract |
| **合同变更** | Contract Change | 已签署合同的修改（金额、条款、产品等），保留变更历史。 | contract |
| **发票** | ContractInvoice | 向客户开具的发票。可关联合同/收款计划/收款记录。 | contract |
| **收款计划** | PaymentPlan | 合同约定的各期收款安排。含：计划收款日期、计划金额、已收金额、状态。 | contract |
| **收款记录** | PaymentRecord | 实际收到的款项记录。核销对应收款计划。 | contract |
| **工商抬头** | BusinessTitle | 客户企业的开票信息（企业名称、税号、地址、电话、开户行、账号）。 | contract |
| **订单** | Order | 合同下的正式执行单。含产品明细、阶段、金额。合同可拆多个订单。 | order |
| **订单阶段** | OrderStage | 订单的执行进度节点。默认：待执行、执行中、已发货、已签收、已完成。 | order |
| **产品** | Product | 可售卖的商品或服务的标准定义。含产品分类、描述、图片等。 | product |
| **产品价格** | ProductPrice | 产品的价格表。支持多维度定价（不同客户/数量/时间的差异化价格）。 | product |
| **跟进计划** | FollowUpPlan | 针对线索/客户/商机的下次跟进安排（时间、方式、内容）。 | follow |
| **跟进记录** | FollowUpRecord | 实际的跟进动作记录（沟通方式、内容纪要、附件）。 | follow |
| **评论** | Comment | 对跟进记录或业务对象的备注/讨论。 | follow |
| **仪表盘** | Dashboard | 数据可视化看板。由多个模块（Module）组合而成，支持收藏。 | dashboard |
| **审批流** | ApprovalFlow | 业务单据的审批流程定义（节点、审批人类型、流转条件）。 | approval |
| **审批节点** | ApprovalNode | 审批流中的单个步骤。含：审批人类型（指定人/角色/上级/发起人自选）、加签、驳回等。 | approval |
| **自定义表单** | CustomForm | 用户可自行设计的表单（字段布局、校验规则）。用于个性化业务数据录入。 | form |
| **全局搜索** | GlobalSearch | 跨模块的关键词搜索（线索/客户/商机/合同/联系人等一键检索）。 | search |
| **标讯** | Tender | 招投标信息。从第三方集成或手工录入，辅助销售发现业务机会。 | tender |
| **智能体** | Agent | AI 智能助手配置（MaxKB 等外部知识库接入、技能、调用参数）。 | agent/integration |

## 二、角色与权限术语

| 术语 | 英文标识 | 定义 |
|---|---|---|
| **组织** | Organization | 租户。多租户隔离，数据按组织完全隔离。 |
| **用户** | User | 登录系统的账号。归属于某个组织。 |
| **部门** | Department | 组织内的部门结构（树形）。用户归属于部门。 |
| **角色** | Role | 权限集合的载体。一个用户可拥有多个角色。 |
| **模块** | Module | 系统中的功能模块（线索/客户/商机/合同/...），可配置启用/禁用、菜单顺序。 |
| **权限** | Permission | 对某资源的操作许可（READ/ADD/UPDATE/DELETE/IMPORT/EXPORT/SYNC/RECYCLE 等）。 |
| **数据权限** | DataScope | 数据可见范围：本人/本部门/本部门及下级/全组织/自定义。 |
| **负责人** | Owner | 某条业务数据（线索/客户/商机等）的主要责任人。默认拥有全部操作权限。 |
| **协作人** | Collaborator | 参与某条数据跟进的辅助人员，拥有部分操作权限。 |
| **API Key** | APIKey | 第三方系统调用 API 的凭证，替代账号密码登录。 |
| **License** | License | 系统授权文件。控制用户数、组织数、过期时间、功能开关。 |

## 三、流程与状态术语

| 术语 | 定义 |
|---|---|
| **转化（线索转客户）** | 线索验证通过，升级为正式客户。线索源信息带入客户，线索本身归档。 |
| **回收** | 超过设定时间未跟进的线索/客户，自动或手动从个人名下回收到线索池/公海。 |
| **分配** | 管理员将线索池/公海中的数据批量指定给销售人员。 |
| **领取** | 销售人员主动从线索池/公海中领取数据（需容量未满）。 |
| **移交** | 将自己负责的数据转给其他销售人员（需对方接收或管理员操作）。 |
| **转办** | 审批节点中将当前审批转给他人处理。 |
| **加签** | 审批流程中临时增加一个或多个审批人，不改变原流程。 |
| **驳回** | 审批不通过，退回到发起人或指定节点。 |
| **作废** | 合同/订单等单据因错误或取消而失效（保留记录但不可操作）。 |
| **归档** | 合同/订单等业务单据执行完毕或结束后的状态，进入历史档案。 |

## 四、集成与技术术语

| 术语 | 英文标识 | 定义 |
|---|---|---|
| **MCP Server** | MCP | Model Context Protocol Server。端口 8082，向外部 AI 助手暴露 CRM Skills（智能创建、录入、查重等）。 |
| **Cockpit** | Cockpit | 智能服务后端。端口 8088，提供更复杂的 AI 能力调度。 |
| **MaxKB** | MaxKB | 外部 AI 知识库系统。通过 integration/agent 接入，用于知识库问答。 |
| **DataEase** | DataEase | 开源 BI 可视化平台。通过 integration/dataease 接入，用于高级仪表盘。 |
| **企查查** | QCC | 企业信息查询平台。通过 integration/qcc 接入，一键补充客户工商信息。 |
| **SSO** | SSO | 单点登录。支持 OAuth 协议与第三方身份系统对接。 |
| **钉钉/飞书/企微** | Dingtalk/Lark/WeCom | 主流办公平台。支持：组织架构同步、消息通知、OAuth 登录。 |
| **Flyway** | Flyway | 数据库迁移工具。管理 DDL/DML 脚本的版本化执行。 |
| **Shiro** | Shiro | Apache Shiro 安全框架。用于认证与授权。 |
| **Session Redis** | Session Redis | 用户 Session 存储在 Redis 中，支持多实例水平扩展。 |
| **UID** | UID | 分布式唯一 ID。基于 Snowflake 改进版：64bit（1+30+21+12），epoch=2025-01-01。 |
