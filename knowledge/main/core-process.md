# Cordys CRM · 核心业务流程

> 本文件描述跨应用的主干业务链路。单个应用内部实现细节请查对应 applications/ 文档。

---

## 一、销售全链路全景

```
                    ┌──────────────────────────────────────────────────────────┐
                    │                    Cordys CRM 销售漏斗                    │
                    └──────────────────────────────────────────────────────────┘

  营销获客 ──→ 线索录入/导入 ──→ 线索分配/领取 ──→ 线索跟进 ──→【转客户】
                                                                │
                                                                ▼
  公海回收 ←── 超时未跟进 ←── 客户跟进 ←── 客户分配/领取 ←── 客户创建
                                                                │
                                                    ┌───────────┴───────────┐
                                                    ▼                       ▼
                                              新建商机(赢单率低)          合同直签
                                                    │
                                                    ▼
  输单归档 ←── 输单审批 ←── 输单确认 ←── 商机跟进 ←── 阶段推进(需求→方案→商务)
                                                    │
                                              赢单(赢单审批)
                                                    │
                                                    ▼
                                              合同创建/审批
                                                    │
                                                    ▼
                                              合同签署 ──→ 合同变更 ──→ 合同履行
                                                                         │
                                                                         ▼
  财务收款 ←── 收款核销 ←── 收款记录录入 ←── 收款计划 ←── 订单创建/发货
                                                                         │
                                                                         ▼
                                              开票申请 ──→ 发票开具 ──→ 订单完成
```

## 二、线索全生命周期

```
  【线索来源】
  ├─ 手工录入      销售/管理员新增线索
  ├─ Excel 导入    批量导入（模板下载→填写→上传→校验→入库）
  ├─ 智能录入      AI 智能体（MCP + Cockpit）自动解析文本/名片
  ├─ 招投标线索    标讯模块一键转线索
  └─ 第三方集成    企查查/营销平台对接

        │
        ▼
  【线索池】  ←──────────────────────────────┐
  │  未分配/被回收的线索在此暂存               │
  │  ├─ 管理员：批量分配给销售人员            │
  │  └─ 销售：主动领取（需容量未满）          │
        │                                    │
        ▼                                    │
  【个人线索】                                │
  │  状态: NEW(新建) → FOLLOWING(跟进中) → INTERESTED(感兴趣)
  │
  ├─ 正常路径：持续跟进 → 【转客户】
  │           └─ 转客户时：验证信息 → 创建客户/联系人 → 线索归档
  │
  ├─ 回收路径：超过设置天数未跟进 → 自动回收到线索池
  │                       或管理员手动回收 ──────────────┘
  │
  └─ 作废路径：标记无效 → 归档
```

**关键规则**：
- 线索转客户为不可逆操作（转完线索即归档，不可"退回"为线索）
- 线索容量超限：无法领取/接收新分配
- 线索池分配/领取均有操作日志

## 三、客户/公海生命周期

```
  【客户创建】
  ├─ 线索转客户（最常见）
  ├─ 手工新增
  ├─ Excel 导入
  └─ 企查查一键录入

        │
        ▼
  【公海】 ←─────────────────────────────────┐
  │  无人负责的客户在此暂存                    │
  │  ├─ 管理员：批量分配                      │
  │  └─ 销售：主动领取（需容量未满）           │
        │                                     │
        ▼                                     │
  【我的客户】                                 │
  │  主负责人 + 协作人                          │
  │  ├─ 客户基本信息维护                       │
  │  ├─ 联系人维护（一主多从）                 │
  │  ├─ 关系图（客户-联系人-商机-合同视图）     │
  │  ├─ 跟进计划/跟进记录                      │
  │  ├─ 创建商机/合同/订单                     │
  │  ├─ 移交（转给其他销售）                   │
  │  └─ 协作（邀请其他销售参与）               │
        │                                     │
        ├─ 超时未跟进 → 自动回收到公海 ────────┘
        └─ 管理员手动回收 ────────────────────┘
```

## 四、商机跟进流程

```
  【商机创建】
  ├─ 从客户页面发起（最常见）
  ├─ 从线索转客户时同步创建
  └─ 手工新建

        │
        ▼
  【商机阶段推进】（阶段可配置，默认如下）
  初步接触 → 需求确认 → 方案制定 → 商务谈判 → 合同签订
        │         │         │         │         │
        ├─────────┴─────────┴─────────┴─────────┤
        │              每个阶段                    │
        │  ├─ 更新阶段时记录阶段推进历史           │
        │  ├─ 写入跟进记录                        │
        │  └─ 阶段必填字段校验（可配置）           │
        │
        ├───────────────────────────────────┐
        ▼                                   ▼
  【赢单】                               【输单】
  │  赢单审批（可选，按审批流配置）         │  输单原因必填
  │  → 自动创建合同草稿                    │  → 输单审批（可选）
  │                                        │  → 归档（仍可查询统计）
  ▼
  【合同创建】（见下一章）
```

## 五、合同到收款流程

```
  【合同创建】
  ├─ 赢单后自动创建草稿
  ├─ 手工创建（关联客户/商机）
  └─ 合同复制（基于已有合同模板快速创建）

        │
        ▼
  【合同审批】 按审批流配置（可选）
        │
        ▼
  【合同签署】
  │  状态: PENDING_SIGNING → SIGNED
  │  ├─ 附件上传（签署后的扫描件/PDF）
  │  ├─ 合同变更（CHANGE 状态，保留变更历史）
  │  └─ 作废（VOID，误操作/取消）
        │
        ▼
  【履行中】 IN_PROGRESS
  │  ├─ 关联订单创建/发货
  │  ├─ 收款计划
  │  │    └─ 多期：日期 + 金额 + 状态（未收/部分收/已收）
  │  ├─ 收款记录
  │  │    └─ 实际到款 → 核销对应收款计划
  │  └─ 开票
  │       └─ 开票申请 → 发票号录入 → 记录发票信息
        │
        ▼
  【履行完毕】 COMPLETED_PERFORMANCE → 【归档】 ARCHIVED
```

## 六、订单执行流程

```
  【订单创建】
  ├─ 合同下创建订单（一个合同可多订单）
  └─ 订单关联产品/数量/单价（自动计算金额）

        │
        ▼
  【订单审批】（可选，按配置）
        │
        ▼
  【订单阶段推进】（阶段可配置）
  待执行 → 执行中 → 已发货 → 已签收 → 已完成
        │
        ▼
  【订单完成】 → 关联收款状态更新
```

## 七、审批流通用流程

```
  【单据提交审批】
  │  合同/订单/工商抬头/赢单/输单 等
  │  按模块 + 条件匹配审批流定义
        │
        ▼
  【启动审批流实例】
  │  按节点依次流转
  │  节点类型: 指定人 / 角色 / 直属上级 / 发起人自选 / 连续多级上级
        │
        ▼
  【当前节点】
  ├─ 通过 → 进入下一节点 / 审批通过
  ├─ 驳回 → 退回到发起人 / 指定节点
  ├─ 加签 → 临时插入一个或多个审批人
  ├─ 转办 → 转给他人代审
  └─ 撤销 → 发起人撤销审批
        │
        ▼
  【审批通过】 → 单据状态更新 → 触发后续业务逻辑
  【审批驳回】 → 单据状态回退 → 发起人修改后可重新提交
```

## 八、跟进与通知通用流程

```
  【跟进计划】
  ├─ 针对线索/客户/商机/合同创建
  ├─ 指定跟进时间、方式（电话/拜访/邮件/会议）、备注
  └─ 到期提醒（系统通知 + 可选企微/钉钉/飞书）

        │
        ▼
  【跟进记录】
  ├─ 跟进方式、内容、附件、关联对象
  ├─ 自动写入操作日志
  ├─ 支持 @评论 通知相关人员
  └─ 下次跟进计划（可从记录直接创建）

  【消息通知】
  ├─ 站内信（系统消息中心）
  ├─ 邮件（按配置开关）
  └─ 第三方（企微/钉钉/飞书，按模块+事件配置）
  通知触发事件: 审批/分配/移交/回收/到期/评论/...
  配置入口: backend/crm/src/main/resources/task/message_task.json
```

## 十、权限检查通用规则（贯穿所有流程）

```
  任何业务操作前，系统依次检查:
  1. 登录认证（Shiro Session / API Key）
  2. 功能权限 @CsPermission（permission.json 定义的节点）
  3. 数据权限 DataScopeService（本人/本部门/本部门及下级/全组织）
  4. 审批节点判断（审批中单据限制某些操作）
  5. 负责人/协作人校验（个人专属操作）
  6. 容量校验（领取/分配前检查线索/客户容量）
```
